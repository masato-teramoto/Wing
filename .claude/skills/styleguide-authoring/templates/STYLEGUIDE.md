### 4-1. Button（`class: .btn-primary` / `.btn-secondary` / `.btn-danger` / `.btn-text`）

- **形**: 高さ `control.height`、角丸 `radius.{{sm}}`、横パディング `spacing.md`、ラベルは `size.body` / medium
- **種類**: primary（ブランド面 + 白文字）/ secondary（白面 + 境界 `border.strong` + 本文色）/ danger（エラー面色）/ text（面なし・リンク色）
- **状態**: hover（`primary_hover` / secondary は `surface.subtle`）/ focus-visible（`control.focus_ring` + 2px offset）/ disabled（不透明度 0.5・カーソル既定）/ loading（ラベル横に進行表示・押下不可）
- **描く要素**: {{可視ラベル（必須）/ アイコン（任意・位置）/ loading の進行表示}}（この欄の形は全部品に置く）
- **使う場面**: 1 画面に primary は 1 つ。破壊的操作は danger + 確認ダイアログ。
  **入れ物の条件**: {{モーダルの中 / アクション行 / 表のセル内 — 置かれうる器を数え上げてから寸法を決める}}
- **禁止**: 押下時の scale・transform / アイコンだけのボタンに可視ラベル無し

### 4-2. 入力欄 Field（`class: .field` / `.field-input` / `.field-label` / `.field-help` / `.field-error`）

- **種類**: text / textarea（複数行になりうる入力は 1 行化しない）/ number（単位は入力欄の右外に接尾）/ date（`yyyy/MM/dd` 入力・表示は §7 の表記）

## 5. レイアウトの原則（Layout Principles）

- **基準**: PC `layout.viewport_base`（実効高 約 650px）。1 業務画面の入力・閲覧対象を**スクロール無しで収めることを目標**にする（努力目標。収まらない場合はセクション単位でスクロール）
- **余白**: `spacing` の段だけを使う。段は詰めても飛ばさない
- **段組み**: フォームは最大 {{4}} 列グリッド、詳細は名前-値の 2 列
- **アクション行**: {{例: フォームは本体下部に右寄せ（primary を右端）。長大なフォームでは下部 sticky 可}}
- **揃え**: 見出し・ラベルは左揃え。右揃えは「値が縦に並ぶ列」だけ
- **ラベルと単位**: 項目ラベルは入力欄の前（上）、単位ラベルは値の直後（接尾）
- **禁止**: 文字サイズの縮小で収める / 必須項目の折りたたみ / 本文を中央寄せの狭幅にする（`content_max_width: none` の場合）

## 6. 奥行きと階層（Depth & Elevation）

| 段 | トークン | 使う場面 |
|---|---|---|
| なし | `elevation.none` | 表・入力欄・ページ内のカード（枠線で区切る） |
| カード | `elevation.card` | 浮かせたいカード・ドロップダウン |
| オーバーレイ | `elevation.overlay` | Dialog・ポップオーバー |

- 業務画面は段を少なく。**面の色と 1px の境界線で階層を作り、影は 2 段まで**
- 禁止: 色付きの影 / 常時の大きな影 / ガラス風（backdrop-blur）

## 7. Do / Don't（Do's and Don'ts）

**Don't（禁止 — 全画面共通）**

- 絵文字を UI 文言に使わない / 記号文字（✓ ✕ ▼ + 等）をアイコン代わりに使わない
- グラデーション・写真・イラスト・テクスチャ・独自の装飾色を使わない
- マーケ調の見出し・ヒーローセクションを業務画面に入れない
- ブランド色で状態の意味を表さない
- **状態色（`status.*`）を状態以外に使わない** — 表のセルの面・ラベル・ページの背景・区切り・
  用途別ボタン・装飾に使わない（既存 UI がそう使っていても踏襲しない）
- 押下時の scale・transform / 明朝体
- {{既存 UI の禁止事項を追記}}

**Do（推奨）**

- 文言は敬体（です・ます）。命令形にしない。専門用語は要件の用語集に従う
- 空状態: 「まだ〜はありません」+ 次にできる行動を 1 つ
- 操作完了: 結果を短く言い切る（「保存しました」）。装飾語・感嘆符・詫びを付けない
- エラー: 復帰手段を先に、詫びは短く（「読み込めませんでした。再試行してください」）
- 入力エラー: 具体的な内容と訂正方法を入力欄の直下に
- **表記**: 日付は `yyyy年MM月dd日`（表では `yyyy/MM/dd` 可・同一画面で統一）、数値・金額は 3 桁区切り + 単位
- 押せる要素は `radius.sm`、押せない表示要素（Badge）は `radius.full`（形で操作可能性を区別する）

   §4 の部品クラスで指定し、**hex / rgb / px の生値をページ側に書かない**
