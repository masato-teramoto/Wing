### ログ方針

#### ログレベル

| レベル | 用途 |
| --- | --- |
| `error` | 例外の発生。スタックトレースを出力する（`ExceptionResolver`）。権限エラー・CSRF エラーもここに含む |
| `warn` | 処理は継続するが利用者・運用者の確認が必要な事象 |
| `info` | バッチのタスク・ジョブの開始／正常終了（メッセージID `GEF-0100xx` 系）など、運用が追跡する節目 |
| `debug` | 開発・調査用の詳細。`jp.co.kccs` ロガーの既定レベル（`log4j2.xml`） |

#### 出力する

| # | 項目 |
| --- | --- |
| 1 | 日時（`yyyy/MM/dd HH:mm:ss.SSS`）・スレッド名・ログレベル・ロガー名・メッセージ（`log4j2.xml` の `format1`） |
| 2 | ユーザーID（`%X{userid}`）とグループID（`%X{groupid}`） |
| 3 | 例外のスタックトレース（`error` レベル） |
| 4 | 権限エラー時のユーザーID・メニューID・機能ID（`security.md` の `## セキュリティログ`） |
| 5 | バッチのタスク・ジョブの開始／終了とメッセージID |

#### 出力しない

| # | 項目 |
| --- | --- |
| 1 | パスワード（平文・ハッシュとも） |
| 2 | セッションID・CSRF トークン |
| 3 | アップロードされたファイルの中身 |
| N | <LOG_EXCLUDE_N>（不要 / 人間 2026-09-11: 既存 WiNG の運用に従う） |

#### ログフィールド標準

> 出力形式は `PatternLayout` によるプレーンテキスト（`log4j2.xml` の `format1`）でプロジェクト確定する。
> 形式にかかわらず **フィールド名・型・意味** を全サービスで統一する。

| フィールド | 必須 | 型 | 値の規約 | 例 |
| --- | --- | --- | --- | --- |
| 日時 | 必須 | 日時 | `yyyy/MM/dd HH:mm:ss.SSS` | `2026/09/11 10:13:59.123` |
| スレッド名 | 必須 | 文字列 | `%t` | `http-nio-8080-exec-1` |
| ログレベル | 必須 | 文字列 | `%p` | `ERROR` |
| ユーザーID | 必須 | 文字列 | `%X{userid}`（MDC） | — |
| グループID | 必須 | 文字列 | `%X{groupid}`（MDC） | — |
| ロガー名 | 必須 | 文字列 | `%c{10}` | `jp.co.kccs.wt.common.handler.ExceptionResolver` |
| メッセージ | 必須 | 文字列 | メッセージID + 文言、または例外メッセージ | `GEF-000000：...` |

| # | 禁止事項 |
| --- | --- |
| 1 | ログに文言を直書きしない（利用者向けの文言は `messages.properties` のメッセージID経由） |
| 2 | 機密情報（上記「出力しない」）をログに含めない |
