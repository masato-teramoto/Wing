Q-DS-PBI-011 その2（遷移の定義が無いボタン・状態遷移表）

■ 2. 遷移の定義が無いボタン
出しません。状態遷移表で定義が無い操作（表で "N" のもの、表に無いもの）は、ボタンを非表示にします。
古い画面のまま押されたときに備えて、サーバー側でも、今のステータス・状態区分と操作の組合せを確かめます。合わなければ WTG-100030 で止めます。

なお、例に挙がった2つは、どちらも定義があります。
- 稟議・修正稟議の 受付済・回覧中 で、申請者の「申請」→ 申請済・回覧中
- 再製本の 起案済・回覧中 で、申請者の「確認」→ 申請済・回覧中

ボタンを出す状態の一覧（状態遷移表）
【稟議・修正稟議】
| ステータス・状態 | 起案者 | 申請者 | 確認者 | 承認者 |
|---|---|---|---|---|
| 未起案・下書き | 更新、削除、申請依頼（→起案済・回覧中） | - | - | - |
| 起案済・回覧中 | - | 発番（発行依頼書の画面。→受付済・回覧中） | - | - |
| 受付済・回覧中 | - | 更新、確認（→受付済・確認中）、申請（→申請済・回覧中）、差戻し（→受付済・差戻し）、取下げ（→受付済・取下げ） | - | - |
| 受付済・差戻し | 更新、取下げ（→受付済・取下げ）、申請依頼（→受付済・回覧中） | - | - | - |
| 受付済・確認中 | - | 更新、確認（状態は変えない）、申請（→申請済・回覧中）、差戻し（→受付済・差戻し）、取下げ（→受付済・取下げ） | - | - |
| 申請済・回覧中 | - | - | 更新、確認（→確認済・回覧中）、差戻し（→申請済・差戻し）、取下げ（→申請済・取下げ） | - |
| 申請済・差戻し | - | 更新、確認（→受付済・確認中）、申請（→申請済・回覧中）、差戻し（→受付済・差戻し）、取下げ（→申請済・取下げ） | - | - |
| 確認済・回覧中 | - | - | - | 承認（→承認済・完了）、差戻し（→確認済・差戻し） |
| 確認済・差戻し | - | - | 更新、確認（→確認済・回覧中）、差戻し（→申請済・差戻し）、取下げ（→確認済・取下げ） | - |
| 取下げ・取込中・承認済・完了 | - | - | - | - |
