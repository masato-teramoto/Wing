Q-DS-PBI-011 その3（requirements との食い違いの扱い：1:B / 2:A / 3:A / 4:起案者は B・承認者は A / 5:A）

C でお願いします。1:B / 2:A / 3:A / 4:起案者は B・承認者は A / 5:A です。A の項目は、まとめて1件の差戻し候補（property-basic-info requirements）として出してください。

1：B。requirements 3.3 のとおり、再製本で申請者が押すボタンは「申請」です。前回の表で「確認」と書いたのは誤りでした。再製本の申請者のボタンは「申請」（起案済・回覧中 → 申請済・回覧中、申請済・差戻し → 申請済・回覧中）で、「確認」ボタンはありません。

2：A。稟議・修正稟議の申請者は、受付済・回覧中、受付済・確認中、申請済・差戻し のどれからでも「申請」でき、申請済・回覧中 になります。受付済・確認中 は「申請者が確認作業中であることを示す印」で、担当者の段階ではありません。確認中を通らずに申請しても、確認者・承認者は飛ばさないので、3.8 の「段階を飛ばす操作」にはあたりません。requirements 2.5 を「申請者は、受付済・回覧中、受付済・確認中、申請済・差戻し から申請できる」に直してください。

3：A。受付済・確認中 で申請者が「確認」を押しても、ステータス・状態区分は変わりません（承認履歴に判定 03 の行を残すだけ）。受付済・回覧中 と 申請済・差戻し で押したときは 受付済・確認中 になります。この「確認中のままの確認」を requirements に足してください。

4：
- 起案者は B。起案者には 未起案・下書き でも「取下げ」を出します（稟議・修正稟議・再製本とも）。取下げは状態区分だけを 取下げ にし、ステータスは変えません（未起案・取下げ になる）。requirements 4.5 のとおりで、前回の表から抜けていました。
- 承認者は A。承認者には「取下げ」がありません（稟議・再製本とも、承認と差戻しだけ）。requirements 4.5 を「番が回っている起案者・申請者・確認者は取下げを受け付ける。承認者は取下げを持たない」に直してください。

5：A。稟議・修正稟議の 起案済・回覧中 は、申請者の番ですが、できるのは発行依頼書の画面での発番だけです。差戻し・取下げは受け付けません。requirements 4.3 と 4.5 に「ただし、稟議・修正稟議の 起案済・回覧中（発番前）は除く」を足してください。再製本の 起案済・回覧中 では、申請者は差戻し・取下げができます（4.3・4.5 のとおり）。

前回の表は次のように直してください。
- 再製本の申請者の「確認」→「申請」
- 未起案・下書き の起案者に「取下げ（→未起案・取下げ）」を追加（稟議・修正稟議・再製本とも）
