# アーカイブ: organization-search-zoom（2026-09-24 廃止）

`organization-search-zoom` feature は 2026-09-24 に廃止した。本ディレクトリはその成果物の退避先であり、**下流フェーズの入力にしない**。

## 廃止の理由

2024-06-25 に ZOOM 管理台帳から `ZWTZ072` を廃止した設計変更が確定したため（人間判断 / 2026-09-24。RFP §4-6 からの変更、合意済み）。作成組織の入力は、呼び出し元だった物件基本情報登録変更画面と発行依頼書登録変更画面に**直接置く**形に変わった。

技術的な裏付けは Phase 5 の設計調査で既に得られていた（`specs-organization-search-zoom/design.md` の 判断 3 / 判断 5）。部署・所属に相当するマスタが既存 WiNG に存在せず、3 項目をプルダウンで検索する構造が成立しないため、ZOOM 画面は「会社を選び、所属をテキストで書いて確定する」だけの画面になっていた（既存 ZOOM 17 本に前例が無い形）。

## 引き継いだ調査結果

改訂後の REQ-048 / REQ-049 / REQ-050 の根拠として、本ディレクトリの `design.md` から次を引き継いでいる。

| 事項 | 内容 | 出所 |
|---|---|---|
| 会社名の取得元 | コードマスタ `TWTZM040` の `WTG` / `PARAM` / `P26`（`Key3` = 会社コード、`MEISHO` = 会社名）。`WTX_Batch` の発行依頼書取込バッチ（`PWTGB090Job`）が同じ行から契約稟議起案者の会社名を取っている | 判断 3 |
| 所属①②の保存先 | `TWTGM100` の `Keiyaku_Ringi_Kiansha_Shozoku1` / `Keiyaku_Ringi_Kiansha_Shozoku2`（各 100 桁） | 判断 3 の追加提示 |
| 部署・所属のマスタ不在 | コードマスタに相当するキーが無く、新設もしない。3 階層のマスタを持つ構造は採らない | 判断 3 |
| `P27` / `P28` | 契約稟議の状態管理用に予約済み。作成組織には使用しない | 判断 3 の代替案 |
