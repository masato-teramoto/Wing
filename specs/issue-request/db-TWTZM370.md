# TWTZM370 税率ﾏｽﾀ の DB レイアウト（Q-DS-IR-011）

- 共通（WTZ）の表として今回の案件で新しく作る（DB レイアウトは WTZ_共通、2024/11/11 新規作成）。使うのは発行依頼書登録変更だけなので、定義は本 feature の design に書く
- 主キー：持たない。一意キー AK_TWTZM370_1 ＝ CompanyCD ＋ Tax_Rate
- 画面からの保守は無い（参照だけ）。行は移行で投入する
- 税率は小数で持つ（10% なら 0.10）。計算は「金額×税率」「金額÷(1＋税率)×税率」
- 適用終了日の列は無い。ある日の税率は「適用開始日 ≦ その日」の行のうち適用開始日がいちばん新しい行
